顶栏 ​

标签栏和工具栏统称为顶栏。

标签栏 ​

在应用配置里设置：

ts
import { 
setSettings
 } from '@fantastic-admin/settings'

export default 
setSettings
({
  
topbar
: {
    
tabbar
: true,
  },
})

标签栏更多配置请点这里。

工具栏 ​

在应用配置里设置：

ts
import { 
setSettings
 } from '@fantastic-admin/settings'

export default 
setSettings
({
  
topbar
: {
    
toolbar
: true,
  },
})

标签栏更多配置请点这里。

模式 ​

在应用配置里设置：

ts
import { 
setSettings
 } from '@fantastic-admin/settings'

export default 
setSettings
({
  
topbar
: {
    
mode
: 'static',
  },
})

切换显示标签栏和工具栏的显示顺序 专业版 ​

在应用配置里设置切换：

ts
import { 
setSettings
 } from '@fantastic-admin/settings'

export default 
setSettings
({
  
topbar
: {
    
switchTabbarAndToolbar
: true,
  },
})
